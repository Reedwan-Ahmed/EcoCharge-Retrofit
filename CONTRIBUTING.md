# Contributing

Thank you for helping improve EcoCharge Retrofit.

1. Do not turn estimates into results. Label figures as simulation, bench measurement, field measurement, or estimate.
2. Include test conditions: battery chemistry/configuration, charger model, instrument, calibration date, input voltage, ambient temperature, firmware commit, and duration.
3. Safety-critical changes to relay control, gate drive, limits, isolation, protection, or termination require engineering review and a documented test plan.
4. Do not publish personal contact details without permission.
5. Do not upload proprietary manufacturer documents without redistribution permission.

Suggested workflow: fork, create a focused branch, explain the change, update documentation and tests, run pio run for firmware changes, and state what has not been tested on hardware.
